# 词汇卡 · 四级+专升本

一个手机端背单词工具，单文件 HTML，不用装 App、不用联网，打开就能背。

## 为什么要做它

备考背单词时踩过的坑，就是做这张卡的理由：

- **词看着眼熟，意思却想不起来**：很多单词明明背过，可一见到它，只认得"这张脸"，意思卡在嘴边就是蹦不出来
- **意思张冠李戴**：有些词会把意思记串，安到长相相近的另一个词头上，形近词之间互相"捣乱"，越背越乱
- **背了总忘**：以前背得滚瓜烂熟的词，隔一段时间再翻，忘得差不多了，反复遗忘特别打击人
- **想背的时候手边没工具**：纸质书不随身带，排队、等车、睡前这些零碎时间全浪费了，缺一个拿起来就能背的东西

所以就有了这张卡：把四级 + 湖北专升本两线的词装进一个文件里，手机随时掏出来就能背。

## 功能

- **5555 词全量收录**：四级 + 湖北专升本双线词汇，含音标、词性、释义、形近词、近义词
- **四种背诵模式**：顺序背、随机背、错词本、查找
- **进度自动保存**：掌握程度、错词、今日进度存在浏览器本地，关掉再打开不丢
- **单文件零依赖**：一个 HTML 走天下，手机、电脑通用

## 怎么用

1. 用手机或电脑浏览器打开 `词汇卡.html`
2. 建议添加到手机主屏幕，当成一个"背单词 App"用
3. 进度存在浏览器 localStorage，换设备不跟随
